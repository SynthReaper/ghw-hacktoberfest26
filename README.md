# MLH x Hacktoberfest Challenge Projects (2026)

Workspace containing hackathon projects for DEV Hacktoberfest Challenges.

## Projects

- [`paper-trail/`](./paper-trail/): **Paper Trail** — Offline Local Walk Generator & Analog Field Card (DEV Hacktoberfest Open-Source AI Challenge Week 1: *Touch Grass*).
- [`switchable/`](./switchable/): **Open-Switch** — Autonomous evaluation and migration engine to verify whether open-weight models (Gemma 2, Llama 3, Qwen 2.5) can safely replace expensive closed LLMs with honest statistics (10k bootstrap 95% CIs), default-deny provenance guard, calibrated pairwise judging, and LoRA fine-tuning break-even economics (DEV Hacktoberfest Open-Source AI Challenge Week 2: *Side Hustle*).
- [`couchpotato/`](./couchpotato/): **CouchPotato Expenses** — Zero-Click Invoice & Receipt Hunter. Autonomous background worker that navigates recurring portals via Browserbase (Stagehand v4), extracts financial metadata with 100% offline privacy via local Gemma 2 (Ollama), classifies IRS Schedule C tax write-offs and flags abnormal bill spikes via Prior Labs TabPFN-3.5 FastMCP, orchestrated by Mastra with Sentry distributed tracing and a Next.js 15 Sloth Command Center (DEV Hacktoberfest Open-Source AI Challenge Week 3: *Slow and Steady* / International Sloth Day).
