# First-user outreach (send Wed/Thu; aim for one live session Sat)

**Short version (DM/WhatsApp):**
Hi <name>, I'm building a small open-source tool for a hackathon that tests whether a team can swap an expensive closed LLM for an open model on its own task, and shows the savings with confidence intervals. You use <their LLM workflow> — could I run it on ~100 example prompts (anonymised; it can run fully on my laptop, nothing uploaded) and tell you what I find? 30 minutes, free. In return I'd love honest feedback, including whether you'd ever pay for a report like this.

**What I need from them:** 50–200 example inputs plus the answers their current model gave (anonymised or synthetic), the model name/price they pay, rough monthly volume.

**After the session, ask exactly:**
1. Did the result surprise you?
2. Would you act on it? What would stop you?
3. Would you pay for an audit like this, and roughly how much?
4. What would you need next?

Record answers verbatim in `docs/evidence/first-user.md` with their permission to quote anonymously. If the answer is no, report that.
